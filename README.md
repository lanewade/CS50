## Progress

### Problem Set 0 — Scratch

For Problem Set 0, I built **Crab Grab**, a small interactive game where the player controls a crab named Shelly, collects Cheedos to earn points, and avoids moving bananas that subtract points.

This was my first time building a complete program from start to finish. I worked with player input, variables, loops, conditionals, collision detection, random positioning, custom blocks, and audio/visual feedback.

I also spent time debugging the game logic, including preventing repeated collisions from removing multiple points and making sure sprites did not respawn directly on top of each other.
